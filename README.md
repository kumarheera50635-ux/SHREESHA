# SHREESHA V1 + V2
Android Studio starter project.

Flow: “Shreesha” → “जी बॉस, बोलिए।” → command → action → response.

Supported: YouTube, WhatsApp, Chrome, Camera, Settings, Wi‑Fi, Bluetooth, Google.

Important: Android SpeechRecognizer is a prototype wake-word approach, not a dedicated always-on hotword engine. Background microphone behavior can be restricted by Android/device makers. The accessibility service is only a scaffold and requires the user to explicitly enable it in Android settings.

A ChatGPT-like public-information answer system requires an authorized AI/search API or backend; this starter does not include a secret API key.
